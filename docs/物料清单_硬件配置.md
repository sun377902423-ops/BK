# BKSYS-MED 远程医疗会诊系统 — 硬件配置清单（机架方案）

## 一、整体方案说明

所有设备统一安装在一个 **19 英寸标准机柜**中，包含主服务器、存储、网络设备、UPS，集中管理，整洁规范。

### 机柜空间占用概览

```
┌─────────────────────────────────┐
│        1U  理线面板（空）         │
├─────────────────────────────────┤
│        1U  千兆交换机             │  ← 连接所有设备
├─────────────────────────────────┤
│        2U  联想 SR588 主服务器    │  ← 核心业务服务器
├─────────────────────────────────┤
│        2U  固定托盘               │
│         ↕  群晖/绿联 NAS（塔式）  │  ← 影像归档
├─────────────────────────────────┤
│        1U  UPS                   │  ← 断电保护（或放托盘）
├─────────────────────────────────┤
│        1U  理线/空白面板          │
│  ───────── 共 8U（12U 机柜）───  │
└─────────────────────────────────┘
```

> **推荐机柜**：18U 标准 19 英寸机柜，**宽度 600mm × 深度 ≥ 800mm**，放在办公室角落即可。

## 二、核心设备清单

### 2.1 主服务器（2U 机架式）

#### 为什么选 2U 而不是 1U？

| 对比项 | 1U 机架式 | 2U 机架式 |
|--------|----------|----------|
| 机箱高度 | 4.4 cm | 8.9 cm |
| 散热空间 | 很小，风扇高转速（噪音大） | 充足，可用大尺寸低速风扇 |
| 持续运行噪音 | 约 50-65 dB（类似吸尘器） | 约 30-40 dB（类似电脑） |
| 散热能力 | TDP 通常 ≤ 95W | TDP 可达 150W+ |
| 扩展性 | 半高卡，最多 2 个 3.5" 盘位 | 全高卡，4-8 个 3.5" 盘位 |
| 长期稳定性 | 高温持续运行有降频风险 | 散热充分，运行更稳定 |

> **结论**：2U 是 7×24 小时连续运行的合理选择，散热好、噪音低、扩展性强。1U 适合数据中心机房（有空调、无人值守），2U 适合办公室环境。

---

#### 推荐配置：联想 SR588

| 项目 | 配置 | 说明 |
|------|------|------|
| **品牌型号** | 联想（Lenovo）ThinkSystem SR588 | 京东店铺：兰顿专卖店 |
| **结构** | **2U 机架式**（高 86.5mm） | 适合机柜安装 |
| **CPU** | 至强银牌 4309Y（8核16线程，2.8GHz） | 处理全部业务逻辑，够用 |
| **内存** | 32GB DDR4 ECC | 满足 8 场会诊 + 20 人阅片并发 |
| **硬盘（推荐改配）** | **系统：480GB SSD（M.2）+ 数据：2TB HDD** | **原配为 2×2TB HDD，建议改 SSD** |
| 原配硬盘 | 2 × 2TB 机械硬盘（HDD） | 系统启动和影像加载偏慢 |
| **网络** | 千兆 + 万兆双网口 | 充足 |
| **电源** | 550W 冗余电源 | 双电源备份，一个坏了不影响 |
| **尺寸** | 长 763.7mm × 宽 445mm × 高 86.5mm | **注意：机柜深度需 ≥ 800mm** |
| **质保** | 联想 3 年保修 | |
| **参考价** | **约 ¥12,000 — ¥15,000**（看具体定制配置） | |

> **注意**：原配为 2 块 2TB 机械硬盘（HDD），用作系统盘会导致开机慢、阅片加载慢。**建议联系客服改为：480GB SSD（装系统）+ 2TB HDD（存数据）**，或直接一块 4TB SSD。加几百元效果明显不同。

**为什么够用？**

| 业务场景 | 负载说明 | 对该配置的要求 |
|----------|----------|---------------|
| 8 场视频会诊 | 视频转发由 LiveKit 服务处理，CPU 负担轻 | ✅ 8核足够 |
| 20 人同时阅片 | 影像从 SSD 数据盘读取，内存缓存加速 | ✅ 32GB 够用，SSD 加载快 |
| 数据库读写 | 会诊/报告/患者数据，压力不大 | ✅ 轻松应对 |
| 文件存储 | 影像存 NAS，不占用主服务器磁盘 | ✅ 合理分配 |

## 四、端口映射说明

需要在**路由器**上做以下端口映射，将外网访问指向机柜内的主服务器：

| 端口 | 用途 |
|------|------|
| 80 / 443 | 网页访问（HTTPS 加密） |
| 4242 | 接收 CT/MR 影像数据 |
| 7880-7882 | 视频通话信令 |
| 50000-50100 | 视频通话媒体流（UDP） |
